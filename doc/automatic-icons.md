# Автоматическая иконка новой карточки

Studio использует тот же best-effort поиск favicon, что и Classic Configurator: при первом сохранении нового сервиса/закладки с пустым `icon` и HTTP(S) `href`. Явно заданная иконка не меняется. При редактировании существующей карточки автоматического поиска нет. Ошибка или таймаут не блокирует сохранение.

Найденный файл сохраняется локально и отдаётся через `/api/config/icon/<file>`.

Для доверенных LAN/CGNAT сайтов администратор может задать серверный `HOMEPAGE_ICON_DISCOVERY_ALLOWED_ORIGINS` — JSON-массив точных HTTP(S) origins с literal private IPv4 и портом. Loopback, link-local и metadata адреса не разрешаются. Клиент не может передать этот allowlist, а политика обычного ручного скачивания не меняется.

```dotenv
HOMEPAGE_ICON_DISCOVERY_ALLOWED_ORIGINS='["http://192.168.1.20:8080"]'
```

Для автоматического поиска публичные DNS-адреса проверяются и закрепляются на время HTTP(S)-соединения, включая redirect hops. Это предотвращает DNS rebinding на неразрешённую внутреннюю сеть.

Не подставляются иконки сторонней страницы входа после перенаправления на другой hostname. Публикуйте Homepage только за Authentik или другим внешним authentication proxy.

Для существующих карточек используется ручной выбор/загрузка: сайт без favicon не получает случайную иконку.
